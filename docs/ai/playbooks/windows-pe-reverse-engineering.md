# Windows PE Reverse Engineering Playbook

1. Start with [RE Triage](../../../skills/zeaz-re-triage/SKILL.md).
2. Load [Windows PE](../../../skills/zeaz-re-windows/SKILL.md).
3. Use [Static RE](../../../skills/zeaz-re-static/SKILL.md) for control/data-flow analysis.
4. Use [Dynamic RE](../../../skills/zeaz-re-dynamic/SKILL.md) only in an isolated Windows lab.
5. Preserve hash, PE identity, signer/version state, tool versions and confidence.
