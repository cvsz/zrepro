# Safe Fuzzing Playbook

1. Confirm explicit authorization and isolated target.
2. Load [Safe Fuzzing Guidance](../../../skills/zeaz-re-fuzzing/SKILL.md).
3. Define resource/time/network limits.
4. Use synthetic/minimal seed inputs.
5. Record exact target build, harness, corpus and tool versions.
6. Reproduce and minimize crashes.
7. Add regression coverage for verified fixes.
