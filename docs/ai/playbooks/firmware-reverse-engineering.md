# Firmware Reverse Engineering Playbook

1. Hash and preserve the original image.
2. Start with [RE Triage](../../../skills/zeaz-re-triage/SKILL.md).
3. Load [Firmware RE](../../../skills/zeaz-re-firmware/SKILL.md).
4. Prefer offline extraction and emulation.
5. Treat embedded secrets as secrets and redact them.
6. Real-device execution/flashing requires explicit authorization and recovery evidence.
